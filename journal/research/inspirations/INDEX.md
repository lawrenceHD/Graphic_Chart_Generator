# Inspirations de Design — Studio & Landing Charta

> Téléchargées le 2026-11-03 à partir des sélections Pinterest fournies par le propriétaire.
> Emplacement : `journal/research/inspirations/`

Ce dossier regroupe les 8 références visuelles clés sélectionnées pour guider l'interface utilisateur, la mise en page, la palette et le ressenti d'interaction de **Charta** (Landing page, Écran Démarrer, Studio 3 colonnes et Toile de marque).

---

## Galerie des références et correspondances produit

### 1. Néo-Brutalisme & Cartes de Données
- **Fichier** : [`01-neo-brutalism-elearning.jpg`](./01-neo-brutalism-elearning.jpg)
- **Source** : [Dribbble - Zero One Design / Pin](https://pin.it/5Zg4bykAj)
- **Traits visuels** :
  - Bordures noires franches (2px) et ombres décalées nettes (*hard offset drop-shadow*, 0 blur).
  - Palette pastel contrastée (vert sauge, fond vanille chaude, jaune solaire, rose poudré).
  - Typographie monospace / machine à écrire pour les étiquettes et chiffres.
  - Cartes modulaires ultra-découpées avec micro-indicateurs et badges.
- **Application Charta** :
  - Style idéal pour le **panneau d'inspection des contrastes** et la **matrice de couleurs**, ou pour les options de variantes de logo dans le Studio.

### 2. Hero Orbital & Communauté GitHub
- **Fichier** : [`02-discussions-hero-concept.jpg`](./02-discussions-hero-concept.jpg)
- **Source** : [GitHub Discussions Concept / Pin](https://pin.it/3ktJaHy1Q)
- **Traits visuels** :
  - Cercles orbitaux concentriques avec avatars, badges d'état et micro-réactions flottantes.
  - Typographie centrale ultra-lisible, contraste blanc immaculé, mise en valeur du titre principal.
  - Boutons d'action arrondis épurés (*pill buttons*) avec hiérarchie claire.
- **Application Charta** :
  - Idéal pour la **Landing Page** ou l'écran d'accueil interactif, visualisant les écosystèmes générés autour du logo central (mockups, palettes, tokens gravitant autour du logo déposé).

### 4. Mesh Gradient & Grille Blueprint
- **Fichier** : [`04-high-conversion-landing.jpg`](./04-high-conversion-landing.jpg)
- **Source** : [Mindset Health - Mind Matters / Pin](https://pin.it/22d42rqTL)
- **Traits visuels** :
  - Dégradé mesh vaporeux et chaleureux (pêche, lavande, violet doux) en arrière-plan.
  - Grille millimétrée technique de précision avec croix de repère (`+`) aux intersections.
  - Barre de navigation capsule noire et badges de presse monochromes.
- **Application Charta** :
  - Ambiance visuelle idéale pour le **canevas central du Studio** : allier la rigueur mathématique (la grille d'ingénieur/architecte) à l'élégance d'une identité graphique.

### 5. Diagramme Nodulaire & Flux de Statuts
- **Fichier** : [`05-seo-analytics-dashboard.jpg`](./05-seo-analytics-dashboard.jpg)
- **Source** : [Website SEO Analytics Dashboard / Pin](https://pin.it/6NxM0skBp)
- **Traits visuels** :
  - Arbre hiérarchique avec liaisons Bézier délicates reliant les entités.
  - Cartes d'actions avec jauges de progression, pastilles d'assignation et puces de statut (*In Progress*, *To-Do*, *Client send*).
  - Style épuré, blanc sur blanc avec ombres de sustentation très douces.
- **Application Charta** :
  - Représentation du **pipeline d'analyse** (Événements SSE `project_events` : Dépôt logo → Scan SVG → Extraction palette → Calcul contrastes → Génération variantes → Rendu mockups).

### 7. Grille Canvas "Fit Build Launch"
- **Fichier** : [`07-management-transactions-dashboard.jpg`](./07-management-transactions-dashboard.jpg)
- **Source** : [Management System Transactions Dashboard / Pin](https://pin.it/1lqxzcJ3m)
- **Traits visuels** :
  - Onglets de phases clairs en en-tête (*Fit - Build - Launch*, *Vision - Product Goals - FBL Canvas*).

  - Cartes blanches arrondies avec boutons d'actions contextuels discrets (`...`, bouton crayon d'édition rapide).
  - Fond brumeux bleu ciel en haut de page.
- **Application Charta** :
  - **Correspondance exacte avec la section Identité & Récit de marque** de Charta (générée par Gemini en J3-J5) : découpage des 6 blocs fondamentaux (Manifeste, Vision, Valeurs, Ton, Archétype, Règles d'or).

### 8. Moodboard Épinglé & Fil Conducteur
- **Fichier** : [`08-designers-toolkit-sites.jpg`](./08-designers-toolkit-sites.jpg)
- **Source** : [Designer's Toolkit: Sites You Can't Ignore / Pin](https://pin.it/1aCBwbtQ3)
- **Traits visuels** :
  - Métaphore du tableau de liège/carnet de notes avec punaises 3D colorées fixant des fiches pastel.
  - Ligne en pointillés guidant le parcours séquentiel (01 → 02 → 03 → 04 → 05 → 06).

- **Application Charta** :
  - Idéal pour la présentation séquentielle de la charte de marque (parcours étape par étape dans le Studio ou carrousel d'exportation).
