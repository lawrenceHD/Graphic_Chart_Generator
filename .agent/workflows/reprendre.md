---
description: Reprendre le travail là où le dernier agent s'est arrêté (protocole de relais).
---

1. Lire `HANDOFF.md`, puis le fichier le plus récent de `journal/sessions/`, puis `journal/OWNER_DECISIONS.md`.
2. Exécuter `git status`, `git branch --show-current` et `git log --oneline -8`. Si `HANDOFF.md` contredit Git, Git fait foi : corriger `HANDOFF.md` d'abord.
3. S'inscrire comme agent actif dans `HANDOFF.md` et créer `journal/sessions/AAAA-MM-JJ-antigravity-<sujet>.md`.
4. Résumer en 5 lignes au plus : branche, dernière étape vérifiée, prochaine action, questions ouvertes.
5. Suivre `AGENTS.md` en toutes circonstances ; ouvrir `.claude/skills/INDEX.md` pour choisir les skills utiles.
