# QUEUE — demandes entre rôles

> Un rôle qui a besoin d'une modification hors de son périmètre l'écrit ici. Le propriétaire du fichier la traite.
> Format : `- [ ] <de> → <vers> : <demande> (critère de fin : …)`

- [ ] R2 → R3 : brancher `runResearch` (`@app/ai`) dans une étape `research` de `apps/worker` (critère de fin : l'étape appelle `runResearch` et enregistre `outcome.plan` + `outcome.issues`, sans jamais échouer à cause de l'IA).
  - Appel : `runResearch({ transport, visionModel, catalogue: loadFontCatalogue(), readIndex, mode?, recordings?, budget?, now }, { logo: { data, mimeType }, palette })`.
  - `transport` : `createGeminiTransport(...)` (clé en variable d'environnement, validée par Zod côté worker). `readIndex` : `() => Promise<string | undefined>` lisant `corpus-reel/**/index.jsonl` ; retourner `undefined` si absent (mode dégradé, jamais d'exception requise : une exception est traitée comme absence).
  - Retour : `Result<ResearchOutcome, AiError>`. `err` seulement si la palette est invalide. Sinon `ok` avec `source` (`live` | `replay` | `default`), `plan` (`ChartPlan` du contrat, déjà validé par `ChartPlanSchema`, titres en anglais), `research?`, `issues[]` typées (`visual-similarity-unavailable`, `reference-index-missing`, `reference-lines-rejected`, `empty-library`, `research-failed`, `recording-missing`, `replayed`, `replayed-after-failure`, `prompt-injection-suspected`, `plan-invalid` : direction vide ou plan refusé, repli sur le plan par défaut ; `directionToChartPlan` et `defaultChartPlan` ne lèvent jamais), `recording?` (si `now` fourni) et `usage`.
  - Rejeu : `parseRecording(texte)` pour charger les enregistrements (JSON validé Zod, un fichier par recherche), `serializeRecording(outcome.recording)` pour en écrire un. `mode: 'replay'` ne fait aucun appel réseau ; en `live`, un échec (quota, indisponibilité) se rabat sur l'enregistrement de même logo (empreinte `fingerprintLogo`) ou sur un enregistrement de clé `*`.
  - Plafonds : `budget` par défaut `DEFAULT_BUDGET` (6 appels, 4 Mo de corps, 2 000 jetons de sortie). Seuls les modèles `gemini-*` passent ; l'hôte est fixé dans `createGeminiTransport` (aucune URL arbitraire).
  - Texte utilisateur (brief, nom) : `analyzeBrand` neutralise déjà balises et caractères invisibles ; `sanitizeUntrusted` / `looksLikeInjection` sont exportés pour d'autres usages.
